# Code of conduct

LogDeck follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good faith, give and accept constructive feedback, and focus on what is best for the project and its users. Harassment, insults, personal or political attacks, and publishing other people's private information are not accepted.

## Reporting

If someone's behavior in this project bothers you, report it privately to the maintainer ([@wisecort](https://github.com/wisecort)) through **Security → Report a vulnerability** ([direct link](https://github.com/wisecort/LogDeck/security/advisories/new)), starting the title with "Conduct:". Reports are handled confidentially.

The maintainer may edit or remove comments, commits, issues and pull requests that break this code, and may block contributors who repeatedly do so.
